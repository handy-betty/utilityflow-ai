# Training Plan

## Audience
Mock utility office staff, dispatchers, supervisors, QA reviewers, and support users.

## Training Sessions
1. System overview
2. Creating work orders
3. Dispatch workflow
4. QA Review and closeout
5. Reporting bugs
6. Using the AI help assistant responsibly
7. Go-live checklist and support escalation

## Success Criteria
Users can create, assign, update, review, and close a work order using documented workflow steps.
