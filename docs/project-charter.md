# UtilityFlow AI — Project Charter

## Purpose
Build a mock utility work-management system that demonstrates employable skills in software implementation, project coordination, QA testing, training documentation, business systems, and responsible AI support.

## Mock Organization
Dakota Plains Utility Cooperative

## Business Need
The mock utility needs a structured way to receive member requests, create work orders, dispatch technicians, track status, review completed work, document bugs, train users, and provide AI-assisted help based on internal documentation.

## Scope
- Work order workflow
- Dispatch board
- Member records
- QA testing center
- Bug reporting
- Training documentation
- AI help assistant
- Supabase-ready backend
- Vercel deployment

## Out of Scope for MVP
- Native mobile app
- Real billing integrations
- Real outage safety systems
- Live member account data
- Production authentication/permissions

## Portfolio Purpose
This project supports retraining toward project management, QA testing, software implementation, business systems analysis, and technical support roles.
