# QA Test Plan

## Objective
Verify that UtilityFlow AI demonstrates core workflows reliably enough for a portfolio demo and DVR retraining discussion.

## Modules Tested
- Dashboard
- Work Orders
- Dispatch Board
- Members
- QA Testing
- Bug Reports
- Training Docs
- AI Help Assistant

## Test Types
- Manual functional testing
- UI review
- iPad responsive testing
- Documentation review
- AI help answer review

## Entry Criteria
- App runs locally
- Core pages load
- Demo data appears
- Navigation works

## Exit Criteria
- Dashboard loads without errors
- Work orders display correctly
- Dispatch board groups by status
- QA and bug pages display documented records
- AI assistant answers internal help questions
- Known issues are documented
